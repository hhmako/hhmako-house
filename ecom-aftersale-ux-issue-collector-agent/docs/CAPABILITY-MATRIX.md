# 能力边界

| 能力 | 包内实现 | 仍需使用者提供 |
| --- | --- | --- |
| 飞书群实时接收 | 长连接监听、事件解析、文字图片合并 | 自建应用、事件订阅、权限、chat_id |
| 人工 @ 录入 | @ 名称过滤、同一流水线入库 | 机器人进群、正确显示名 |
| 群图片证据 | 下载消息资源、上传 Base 和卡片 | 图片读取权限 |
| 小红书采集 | 授权会话搜索、原帖截图 | 本人授权账号登录态 |
| 微博采集 | 授权会话搜索、原帖截图 | 本人授权账号登录态 |
| 哔哩哔哩采集 | 授权会话搜索、原帖截图 | 本人授权账号登录态 |
| 体验问题判断 | 严格内置规则，可接外部分析器 | 规则表和负责人映射 |
| 多维表格入库 | 真实记录、附件、默认待确认 | Base 权限及字段 ID |
| 实时卡片 | 单条模板 payload、来源/详情链接 | 已发布模板、目标机器人 |
| 双周卡片 | 读取真实记录、双周窗口、未跟进提醒 | 已发布模板、目标机器人 |
| 去重 | 群 message_id、外网来源 URL/标题 | 可选 dedupe 字段 |

本包不会绕过平台登录、风控或组织权限，也不会内置任何真实租户凭证。
