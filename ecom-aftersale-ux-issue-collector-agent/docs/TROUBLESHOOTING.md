# 排障手册

## 群里有新消息但监听器无日志

检查：

1. 应用是否已发布最新版本。
2. 是否订阅 `im.message.receive_v1`。
3. 是否选择长连接接收事件。
4. 机器人是否在目标群中。
5. `config.local.json` 的 chat_id 是否正确。
6. 应用是否有读取群消息和资源的权限。

## 收到文字但没有图片

- 图片可能是后续独立消息，确认 `mergeWindowMs` 足够。
- 检查消息资源下载权限。
- 查看 `candidate_failed` 日志中的 message_id 和 HTTP 状态。

## 问题没有入库

这是预期的严格闸门。查看 `runtime/group-inbox/`：

- 缺少截图。
- 无法确认抖音电商交易场景。
- 没有明确 UI、信息、交互或流程设计异常。
- 属于客服/商家/物流/商品/生活服务/纯技术问题。

## 外网采集为 0

- 刷新对应平台登录态。
- 确认渠道开关表已启用。
- 确认搜索结果能显示原帖发布时间。
- 没有原帖日期或截图的候选会被拒绝。
- 小红书遇到风控时，只能切换合规授权入口或稍后重试，不能绕过风控。

## 卡片发送失败

- 核对模板已发布且变量名一致。
- 核对 webhook 所在群或 `progressBot.chatId`。
- 图片必须是飞书消息图片 `img_key`。
- “查看来源”必须是当前记录的原始帖子或群消息链接。

## `doctor` 报占位符

运行 `npm run setup` 后，打开 `config.local.json` 和 `.env`，按
[配置说明](CONFIGURATION.md) 替换。不要修改 `config.template.json` 写入真实值。
